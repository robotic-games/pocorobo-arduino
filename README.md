# pocorobo-arduino

ポコロボ（Pocorobo）を Arduino IDE でプログラミングするための、ボードパッケージとライブラリです。

> **開発中です。** まだインストールできる配布物はありません。

## 予定している内容

- **ボードパッケージ**: Arduino IDE の「ボード」に Pocorobo Standard / Pocorobo Mini を追加します
- **ライブラリ `Pocorobo`**: サーボ・DC モータ・LED・ブザー・エンコーダ・専用コントローラの入力を、スタジオのブロックと同じ単位で扱えます
- **スケッチ例**

## 対応機種

- Pocorobo Standard
- Pocorobo Mini
